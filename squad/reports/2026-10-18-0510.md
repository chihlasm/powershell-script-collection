## Checklist gaps (personal-data reviewer, verbatim)
- The checklist does not cover the clipboard as a data path. Client data copied to the clipboard should opt out of Win+V history and the cloud clipboard (CanIncludeInClipboardHistory / CanUploadToCloudClipboard = 0). Any fallback that cannot opt out should be visible to the tech at run time, not only in the README. RDP clipboard redirection should be documented.
- The rule "Tests use synthetic data only" should also say tests must never touch real user-facing state on the dev or CI machine (clipboard, profile folders such as %USERPROFILE%\Documents\TicketNotes). This should be enforced by a static guard, not only by per-test fakes, because a missing fake leaks before the test fails.
