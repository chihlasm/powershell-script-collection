How to read these numbers

IOPS: input/output operations per second. Higher = more requests handled. MB/s: throughput. Higher = more data moved. Latency: how long each I/O takes. Lower = snappier. P95/P99: the slowest 5%/1% of I/Os — outliers that real users feel.

Status bands depend on whether the target was tested as Local storage (this machine’s disk) or Network storage (UNC share or remote VDA). Thresholds match the existing CitrixVDADiagnostics health checks so reports from both tools tell a consistent story.
